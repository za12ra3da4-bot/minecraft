# FC온라인 스쿼드 코치

원하는 스쿼드를 말로 적으면 AI(Claude)가 **FC온라인** 기준으로 스쿼드와 전술을 짜주는 웹앱이에요.

> 예: "BP 3000억, 토트넘 팀컬러에 손흥민 필수. 역습 4-2-3-1로 짜줘"

## 짜주는 것

- **선발 11명**: 포지션, 시즌 카드와 강화 단계(예: `24TOTY +5`), OVR, 급여, 예상 BP 가격, 역할
- **전술판**: 105m × 68m 비율 피치 위에 포메이션대로 배치. 선수를 누르면 역할과 개인 전술이 나와요
- **벤치** 5~7명과 교체 용도
- **팀 전술**: 수비 스타일, 빌드업 같은 선택형 설정과 수비 폭, 수비 깊이, 공격 폭, 박스 안 선수 수 같은 수치 설정
- **개인 전술**: 선수별 1~3개
- **세트피스 키커**: 주장, 페널티킥, 프리킥, 코너킥
- **상황별 전술**: 선제골 후 잠그기, 지고 있을 때 총공격 등
- **플레이 팁**: 공식경기(직접 조작)면 조작 패턴, 감독모드면 설정 위주
- **대체 선수**: 더 싸거나 더 센 선수

결과가 나온 뒤에는 "좀 더 공격적으로", "예산 20% 줄여서" 처럼 **이어서 수정 요청**을 하면 바꿔달라고 한 부분만 고쳐줘요.
"내 보유 선수로 짜기"에 가진 선수를 붙여넣으면 그 선수들로 짜줘요. "텍스트로 복사"로 결과를 복사해서 공유할 수 있어요.

## 주의

선수 가격, 급여, 카드 정보는 AI가 알고 있는 지식으로 **추정**한 값이에요. 실제 시세와 다를 수 있으니 게임 안 이적시장에서 꼭 확인하세요.

## 실행 방법

### 1) claude.ai에서 바로 쓰기

claude.ai 아티팩트로 배포된 페이지를 열면 API 키 없이 본인 Claude 계정으로 동작해요. 처음 요청할 때 Claude 사용 허용 창이 뜨면 허용해 주세요.

### 2) 내 컴퓨터에서 실행하기

Node.js 18 이상이 필요해요.

```bash
cd fconline-coach
npm install
export ANTHROPIC_API_KEY=sk-ant-...   # Windows PowerShell: $env:ANTHROPIC_API_KEY="sk-ant-..."
npm start
```

브라우저에서 <http://localhost:3000> 을 열면 돼요.

API 키 없이 화면만 확인하려면 `npm run demo`로 실행하세요. 어떤 요청이든 예시 스쿼드로 답해요.

| 환경 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | (필수) | Anthropic API 키 |
| `CLAUDE_MODEL` | `claude-opus-5` | 사용할 Claude 모델 |
| `PORT` | `3000` | 서버 포트 |
| `HOST` | `127.0.0.1` | 다른 기기에서 접속하려면 `0.0.0.0` |

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `public/index.html` | 화면 (전술판, 라인업, 전술 표시, 요청 입력) |
| `public/coach-spec.js` | 코치 프롬프트, 결과 JSON 스키마, 결과 검증, 예시 스쿼드. 화면과 서버가 같이 씀 |
| `server.mjs` | 로컬 서버. Anthropic SDK로 Claude를 호출하고(structured outputs로 JSON 형식 보장) 진행 상황을 스트리밍 |

화면은 실행 환경을 스스로 감지해요. claude.ai 안에서는 아티팩트의 Claude 호출 기능을, 로컬에서는 `server.mjs`의 `/api/generate`를 써요.
