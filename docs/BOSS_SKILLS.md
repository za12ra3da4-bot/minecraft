# 신들의 전쟁: 올림포스 — 보스 전투 확장 설계서

이 문서는 저장소에 실제로 있는 파일만을 근거로 작성했다.

| 폴더 | 실제 위치 (서버) | 비고 |
|---|---|---|
| `Skript/` | `plugins/Skript/` | Skript 2.15.2 + skript-reflect (`01-data.sk` 의 `import:`) |
| `resourcepack/olympus_pack.zip` | 서버 리소스팩 | `pack_format 75` = **1.21.11**, 네임스페이스 `oly` |
| `cerberus/ chimera/ hydra/ medusa/ minotaur/` (저장소 최상위) | `world/datapacks/olympus_bosses/data/oly/function/boss/<id>/` | 업로드가 100개에서 잘려 **일부만** 올라와 있음 (아래 1-3) |

## 1. 현재 구조 분석

### 1-1. Skript — 보스와 연결된 부분

| 파일 | 역할 |
|---|---|
| `10-bossdata.sk` | 자동 생성. 애니메이션 프레임 수/간격, 히트박스 몹 종류, 배율 |
| `10-monsters.sk` | 보스 본체: 일정·소환·구동 루프·예고 장판·패턴·피격·처치·유물 |
| `90-flow.sk` | `/oly boss <id>` 소환, 시대가 `end` 가 되면 `olyBossReset()` |
| `01-data.sk` | `olyCmd` (출력 없는 명령 실행), `olyAB`, `olyOracle`, `olyRtSweep` (`kill @e[tag=oly]`) |
| `02-game.sk` | `olyEnd()` → 시대 `end` → (90-flow) `olyBossReset()` |

보스 한 마리 = **보이지 않는 히트박스 몹**(`olyb_hb`, `olyb_<id>_hb` 태그) + 그 위에 탄 **디스플레이 파츠**(`olyb_<id>_part` 태그, 고정 UUID).

- 소환: `olyBossSpawn` → `summon <몹>` → `function oly:boss/<id>/spawn`
- 구동: `olyBossRun` (1틱 루프) → `oly:boss/<id>/<anim>/<frame>`, 회전 `oly:boss/<id>/rot`
- 1초마다: `olyBossSecond` → 보스바, 잠/깸, 귀환, `olyBossSkill` (패턴)
- 공통 예고: `olyTeleCircle` / `olyTeleRect` (붉은 장판이 차오름, 태그 `olyt_<id>`)
- 사라짐: `olyBossGone` → `oly:boss/<id>/remove`, 보스바 제거, 장판 제거
- 상태 변수: `{oly::m::<id>::alive|awake|grown|mul|maxhp|calm|done}`, 런타임 `{oly::rt::bbusy|bcd|bpose::<id>}`

### 1-2. 리소스팩

- 커스텀 모델 방식: **CustomModelData 가 아니라 1.21.4+ `item_model` 컴포넌트**
  - `assets/oly/items/<boss>/<part>.json` → `oly:boss/<boss>/<part>` 모델, 텍스처 `oly:item/boss/<boss>` (512×512 아틀라스)
  - 따라서 "모델 번호" 충돌은 없고, **경로 이름**만 겹치지 않으면 된다 → 새 리소스는 전부 `oly:fx/…`, `oly:icon/…` 아래에 둔다.
- 없던 것: `sounds.json`, `.ogg`, 폰트, 아이콘, 이펙트 모델 — 이번에 추가

### 1-3. 보스 데이터팩 (업로드된 부분)

| 경로 | 내용 |
|---|---|
| `<id>/<anim>/<n>.mcfunction` | `data merge entity <UUID> {transformation:[…]}` 프레임 |
| `hydra/grow_3..6` | 목 N 번 파츠 7개 `tag … remove oly_hidden` + 펼치기 |
| `cerberus/remove` | `kill @e[tag=olyb_cerberus_part]` |

UUID 규칙 `6f6c7962-0000-000B-0000-0000000000PP` (`6f6c7962` = "olyb")

| B | 보스 | 파츠 | 프레임 좌표로 확인한 부위 |
|---|---|---|---|
| 1 | minotaur | 25 | 5 머리 · **6 눈** (5 와 같은 자리) · 20 도끼 |
| 2 | nemean_lion | 18 | (프레임 미업로드 → 전체 파츠 태그만 사용) |
| 3 | chimera | 29 | **9–13 사자 머리** · **14–21 염소 머리+뿔** · **22–28 뱀 꼬리+머리** |
| 4 | cerberus | 26 | **9–12 머리 A (화염)** · **13–16 가운데 머리 (포효)** · **17–20 머리 B (추적)** · 21–25 꼬리 |
| 5 | hydra | 63 | 목 k 번 = **14+7k … 20+7k** (`grow_3..6` 과 정확히 일치) |

> 이번 작업은 이 파일들을 **만들거나 덮어쓰지 않는다.** 새 파일은 전부 `boss/<id>/fx/` 와 `boss/fx/` 아래에만 추가한다.

## 2. 보스별 정리 — 기존 기능 / 새 스킬 / 리소스

공통 규칙
- 모든 강한 공격은 **시전 → 예고 → 판정** 3단계.
  시전: 보스 머리 위에 스킬 아이콘(아이템 디스플레이) + 보스바 이름에 `[아이콘] 스킬명` + 보스바 노란색 + 근처 플레이어 자막/액션바 + 시전 사운드
  예고: 기존 붉은 장판(차오름) + 스킬 전용 바닥 이펙트(균열·독 웅덩이·지옥문 …)
  판정: 장판 안의 사람만 맞는다.
- 피해를 올리지 않는다. 대신 **패턴의 수·방향·조합**이 체력/머리 수에 따라 바뀐다.
- 각 보스 로직은 `Skript/scripts/10-boss-<id>.sk` 한 파일에, 연출 함수는 `boss/<id>/fx/` 에.

## 3. 정리(클린업) 설계 — 스킬만 남아 도는 버그 방지

| 장치 | 동작 |
|---|---|
| **에폭** `{oly::m::<id>::ep}` | 소환·잠듦·사라짐마다 +1. 모든 스킬은 시작할 때 에폭을 잡고, `wait` 뒤마다 `olySkGo()` 로 확인 → 바뀌었으면 즉시 중단 |
| `olySkGo()` 검사 | 보스 살아 있음 · 깨어 있음 · 게임 진행 중(`olyLive`) · 에폭 같음 · 히트박스 엔티티 살아 있음 |
| 바쁨 감시 | `bbusy` 가 15초 넘게 풀리지 않으면 강제로 푼다 |
| 연출 엔티티 | 전부 `oly`, `olyfx`, `olyfx_<id>`, `olyfx_<key>` 태그 → 보스별/전체 일괄 제거 (`olyRtSweep` 의 `kill @e[tag=oly]` 에도 걸린다) |
| 보스 사라짐 (`olyBossGone`) | `olyBossFxGone()`: 에폭+1, 바쁨·시전·광폭화·절단 상태 삭제, `oly:boss/<id>/fx/clear` (연출·발광·부하·사운드 정지), 영향받은 플레이어 복구 |
| 잠듦 (`olyBossSleep`) | `olyBossFxSleep()`: 에폭+1, 진행 중 스킬 중단, 연출 제거, 플레이어 복구 |
| 게임 일시정지 | `olyBossSecond` 가 `olyLive()` 아니면 새 스킬을 고르지 않고, 진행 중 스킬도 다음 확인 때 멈춘다 |
| 게임 종료 / 리셋 | 기존 흐름(`end` → `olyBossReset` → `olyBossGone`) 그대로 + 위 정리 + `oly:boss/fx/restore_players` |
| 서버 재시작 | `on load`: `kill @e[tag=olyfx]` + 모든 접속자 복구. `on join` / `on respawn`: 석화·속박 수정치 제거 |
| 플레이어 상태 | 석화·속박은 **attribute modifier** (`oly:boss_petrify`, `oly:boss_snare`) 로만 건다 → 병종의 base 이동속도를 건드리지 않고 정확히 떼어낼 수 있다 |

## 6. 서버에서 꼭 확인할 것 (이 환경에선 서버를 돌릴 수 없었음)

- Skript 파싱: `tools/boss_fx/sklint.py` 로 함수 정의/호출 · 인자 수 · 따옴표 · 리소스/함수 참조는 검사했지만,
  Skript 자체 문법(`is blocking`, `custom model data`, skript-reflect 호출 등)은 `/sk reload` 로 확인이 필요하다.
- 메뉴 창 배경: 제목 폰트 글리프 방식. 배경이 아이템 위에 덮이면 알려 줄 것 (1.21.6+ GUI 렌더 순서).
- 발광 · 파티클 위치: 케르베로스 · 키메라 머리 파츠 번호는 프레임 좌표로 역산했다.
