# 왕관 쟁탈전 (4팀 PvP + 미니 보스)

마인크래프트 **1.21.11** 서버용. 맵 · 리소스팩 · 데이터팩 · Skript 가 한 벌이다.

## 받을 파일

| 파일 | 넣는 곳 |
|---|---|
| `arena/resourcepack/bg_arena_pack.zip` | 서버 `server.properties` 의 `resource-pack` (또는 각자 리소스팩 폴더) |
| `arena/datapack/bg_arena/` (폴더째) | `world/datapacks/` |
| `Skript/scripts/arena/` (폴더째) | `plugins/Skript/scripts/` |

필요한 플러그인: **Skript 2.9+**, **skript-reflect** (조용한 명령 실행용).

## 설치 순서

1. 데이터팩 · Skript 파일을 넣고 서버를 켠다 (`/reload` 또는 재시작).
2. 맵을 놓을 곳을 정한다. 기본 원점은 `-128 40 -128` (지면이 y=64, 256×256 칸).
   바꾸려면 `/전장 원점 x y z`, 월드 이름이 `world` 가 아니면 `/전장 월드 <이름>`.
3. `/전장 건설` — 여러 틱에 나눠 맵을 짓는다 (끝나면 채팅 알림). 장식 디스플레이까지 자동 배치.
4. 팀 나누기: `/전장 자동팀` 또는 `/전장 팀 <플레이어> red|blue|green|yellow`.
5. `/전장 시작`.

## 규칙

- **점령 지점 5곳**: 가운데 왕좌의 성소 (초당 +3) · 제단 4곳 (초당 +1 + 팀 버프)
  - 화염 = 힘 I · 백옥 = 저항 I · 청풍 = 신속 I · 녹림 = 회복 · 포만
  - 한 팀만 서 있어야 게이지가 오른다. 여러 팀이 있으면 쟁탈 (멈춤). 남의 지점은 먼저 중립으로 깎아야 한다.
- 처치 +10점. 목표 점수(기본 1500) 또는 제한 시간(기본 30분) → 최고 점수 팀 승리.
- 본진: 적이 안쪽 16칸에 들어오면 초당 2하트 피해, 자기 팀은 회복. 본진의 병과 발판(전사 · 궁수 · 수호자)을 밟으면 병과 변경.
- **미니 보스**: 3분 뒤 첫 등장, 이후 처치/퇴각 5분 뒤. 20초 전 예고 + 등장 시 전체 알림. 네 모서리 투기장 중 한 곳.
  - 가장 많이 때린 팀이 +150점 + 2분 축복 (청동 골렘=저항 · 스핑크스=적 발광 · 히드라=재생 · 사이클롭스=힘).
  - 45초 동안 아무도 없으면 보스가 사라진다.
  - 모든 공격은 바닥에 붉은 먹 경고가 먼저 깔리고, 게이지가 다 차면 그 안에 있는 사람만 맞는다. 강한 공격일수록 경고가 길다.
  - 청동 골렘의 돌진을 기둥으로 유도하면 기절 (받는 피해 1.5배). 히드라의 회복 시전은 강하게 때려 끊을 수 있다.

- **복수의 신 네메시스 (역전 이벤트 · 최종 심판)**: 제한 시간의 절반이 지난 뒤 1등 팀 점수가 2등의 2배 이상(그리고 200점 이상)이면 한 판에 한 번, 20초 예고 후 1등 팀 본진 성벽 바깥 땅 위에 나타난다. 미니 보스보다 훨씬 강하다.
  - 체력 200 + 1등 팀 두 번째 사람부터 1명당 40 (최대 600) · 갑옷 · 한 대 하트 4 + 흡혈 · 넉백 안 먹음 · 120초 뒤 떠남.
  - 1등 팀만 노리고 1등 팀만 때릴 수 있다 · 1등 팀 본진 안으로는 못 들어감, 스킬도 본진 안은 안 맞음 (스폰킬 없음) · 쓰러뜨리면 +50점 · 팀원 코인 +15.
  - 스킬 (6~8초, 격노 4~6초 · 바닥 경고 후 판정): 심판의 검(직선 · 격노 3갈래, 하트 5) · 응보의 저울(최대 5명 발밑, 하트 4 + 구속) · 날개 폭풍(반지름 10, 하트 3.5 + 날림) · 천벌(32칸 안 전원 따라다니는 원 → 벼락, 하트 5). 체력 50% 아래 격노 때 '복수의 그림자'(벡스) 4마리.
  - 모습: 키 9블록 · 날개폭 12블록, 파츠 85개 (`arena/tools/rp/bosses/nemesis.py`, 미리보기 `arena/preview/boss_nemesis.png`). 그림 보스바 (이름판 · 초상화 · 시전 게이지).
  - 관리자: `/네메시스 [팀]` (시험 소환) · `/네메시스 제거`. 배수 `{bg::cfg::nem_ratio}` (기본 2) · 최소 점수 `{bg::cfg::nem_min}` (기본 200) · 보상 `{bg::cfg::nem_reward}` (기본 50).

## 상점 · 전설 무기

`/상점` (자기 본진에서) — 갑옷 · 소모품 · 전설 무기. 시작 장비는 약하다 (가죽·사슬 + 돌 검). 산 장비는 죽어도 유지. `/코인` 으로 잔액.
코인: 시작 20 · 10초마다 +1 · 처치 +10 · 점령 +15(팀 전원) · 점령한 지점 하나당 10초마다 +1 · 보스 처치 +40(팀 전원). 전설 무기 90~150.
무기마다 서양 판타지 2D 아이콘과 우클릭 전용 스킬(빛나는 마법진 바닥 효과)이 있다:
천둥의 성검(낙뢰) · 용살자의 도끼(앞 120° 베기) · 질풍의 레이피어(질주) · 성기사의 전쟁망치(결계) · 흑기사의 대검(돌진 베기) · 그림자 쌍단검(3연속 베기) · 대마법사의 지팡이(띄우기) · 불사조의 창(화염 고리).
무기 그림 원본: `arena/art/weapons/<id>.png` (여기 있는 그림이 우선 들어감).
죽어도 전설 무기는 떨어지지 않고 부활할 때 다시 받는다. 관리자: `/전장 코인 <플레이어|all> <수>`.

## PvP 연습장 (게임이 없을 때 자유 대전)

`/연습장` — 투기장 고르기 화면 (리소스팩 그림: 두 투기장 카드 · 입장 단추). 연습장 안에서 열면 다른 투기장으로 옮기기 · 대기실로 나가기.
- **석영 투기장**: 지름 58칸 원형, 엄폐 기둥 · 관중석.
- **용암 투기장**: 폭 112칸 팔각 흑요석 투기장. 가운데 용암 해자(다리 4개) · 현무암 기둥 엄폐 · 대장간 탑 4(계단) · 동서남북 팀 색 문에서 부활. 미리보기 `arena/preview/pvp_arena2.png`.
- 관리자: `/전장 연습장건설` (둘 다, 처음 한 번) · `/전장 연습장건설 1|2` (하나만) · `/연습장 잠금|열기|전체나가기`.
- `/연습장 1` · `/연습장 2` 로 바로 들어가기, `/무기` 무료 무기고, `/연습장 나가기`.

## 관리 명령 (`/전장`, 별칭 `/bg`, OP 전용)

`건설` · `장식` · `원점 x y z` · `월드 이름` · `팀 <플레이어> <팀|none>` · `자동팀` · `시작` · `종료`
`보스 [talos|sphinx|ladon|cyclops]` (즉시 소환) · `보스제거` · `점수 <팀> <n>` · `목표 <n>` · `시간 <분>` · `이동 <마커>`

업데이트가 실제로 적용됐는지: `/업데이트테스트` (OP) — GitHub 최신 · 서버 파일 · 지금 돌고 있는 스크립트 버전을 비교하고 체력바 상태를 보여 준다. 팀 잠금: `/팀잠금 <팀>` (판이 끝나면 풀림).

명령 오류를 확인하려면 `{bg::cfg::debug}` 를 true 로 (콘솔로 실행되어 로그가 남는다).

## 다시 만들기 (개발용)

```
cd arena/tools
python3 build.py          # 맵 · 데이터팩 · 리소스팩 · Skript 데이터 전부
python3 render_map.py     # 미리보기 이미지 → arena/preview/
```
