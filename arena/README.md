# 신들의 전장 (4팀 PvP + 미니 보스)

마인크래프트 **1.21.11** 서버용. 맵 · 리소스팩 · 데이터팩 · Skript 가 한 벌이다.

## 받을 파일

| 파일 | 넣는 곳 |
|---|---|
| `arena/resourcepack/bg_arena_pack.zip` | 서버 `server.properties` 의 `resource-pack` (또는 각자 리소스팩 폴더) |
| `arena/datapack/bg_arena/` (폴더째) | `world/datapacks/` |
| `Skript/scripts/arena/` (폴더째) | `plugins/Skript/scripts/` |

필요한 플러그인: **Skript 2.9+**, **skript-reflect** (조용한 명령 실행용).

## 설치 순서

1. 데이터팩 · Skript 파일을 넣고 서버를 켠다 (`/reload` 또는 재시작).
2. 맵을 놓을 곳을 정한다. 기본 원점은 `-128 40 -128` (지면이 y=64, 256×256 칸).
   바꾸려면 `/전장 원점 x y z`, 월드 이름이 `world` 가 아니면 `/전장 월드 <이름>`.
3. `/전장 건설` — 여러 틱에 나눠 맵을 짓는다 (끝나면 채팅 알림). 장식 디스플레이까지 자동 배치.
4. 팀 나누기: `/전장 자동팀` 또는 `/전장 팀 <플레이어> red|blue|green|yellow`.
5. `/전장 시작`.

## 규칙

- **점령 지점 5곳**: 가운데 올림포스 대신전 (초당 +3) · 제단 4곳 (초당 +1 + 팀 버프)
  - 아레스 = 힘 I · 아테나 = 저항 I · 헤르메스 = 신속 I · 데메테르 = 회복 · 포만
  - 한 팀만 서 있어야 게이지가 오른다. 여러 팀이 있으면 쟁탈 (멈춤). 남의 지점은 먼저 중립으로 깎아야 한다.
- 처치 +10점. 목표 점수(기본 1500) 또는 제한 시간(기본 30분) → 최고 점수 팀 승리.
- 본진: 적이 안쪽 16칸에 들어오면 초당 2하트 피해, 자기 팀은 회복. 본진의 병과 발판(전사 · 궁수 · 수호자)을 밟으면 병과 변경.
- **미니 보스**: 3분 뒤 첫 등장, 이후 처치/퇴각 5분 뒤. 20초 전 예고 + 등장 시 전체 알림. 네 모서리 투기장 중 한 곳.
  - 가장 많이 때린 팀이 +150점 + 2분 축복 (탈로스=저항 · 스핑크스=적 발광 · 라돈=재생 · 키클롭스=힘).
  - 45초 동안 아무도 없으면 보스가 사라진다.
  - 모든 공격은 바닥에 붉은 먹 경고가 먼저 깔리고, 게이지가 다 차면 그 안에 있는 사람만 맞는다. 강한 공격일수록 경고가 길다.
  - 탈로스 돌진을 기둥으로 유도하면 기절 (받는 피해 1.5배). 라돈의 회복 시전은 강하게 때려 끊을 수 있다.

## 관리 명령 (`/전장`, 별칭 `/bg`, OP 전용)

`건설` · `장식` · `원점 x y z` · `월드 이름` · `팀 <플레이어> <팀|none>` · `자동팀` · `시작` · `종료`
`보스 [talos|sphinx|ladon|cyclops]` (즉시 소환) · `보스제거` · `점수 <팀> <n>` · `목표 <n>` · `시간 <분>` · `이동 <마커>`

명령 오류를 확인하려면 `{bg::cfg::debug}` 를 true 로 (콘솔로 실행되어 로그가 남는다).

## 다시 만들기 (개발용)

```
cd arena/tools
python3 build.py          # 맵 · 데이터팩 · 리소스팩 · Skript 데이터 전부
python3 render_map.py     # 미리보기 이미지 → arena/preview/
```
